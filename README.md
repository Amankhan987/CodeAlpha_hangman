# CodeAlpha_Hangman

A simple text-based Hangman game built in Python as part of the CodeAlpha Python Programming Internship.

## Description
The computer picks a random word and the player guesses it one letter at a time. The player can make a maximum of 6 wrong guesses.

## Features
- Random word chosen from a list of 5 words
- Shows correct letters and underscores for remaining letters
- Maximum 6 wrong guesses
- Detects already guessed letters
- Win and lose messages

## How to Run
1. Install Python
2. Download `hangman.py`
3. Run in terminal: `python hangman.py`

## Concepts Used
random module, while loop, for loop, if-else, strings, lists
